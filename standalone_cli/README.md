# 樱桃货架期预测

## 交互运行

```powershell
python cherry_shelf_life_cli.py
```

## 直接传入温度和硬度

```powershell
python cherry_shelf_life_cli.py 10 60
```

参数顺序：

1. 储藏温度：**0-25 ℃连续范围**，可以输入 0、5、10，也可以输入 7.5、12 等小数。
2. 手持硬度：**60-90 连续范围**，可以输入小数。

### 温度输入说明

本终端程序的温度不是只能选择六个固定值，而是：

```text
0 ℃ <= 储藏温度 <= 25 ℃
```

程序中的 0、5、10、15、20、25 ℃是模型的温度控制点。输入两个控制点之间的温度时，程序会连续计算。例如：

```powershell
python cherry_shelf_life_cli.py 7.5 60
```

## 预测方法

### 1. 方法概述

本程序使用的是一个**确定性的经验组合模型**，不是机器学习在线训练，也不会连接网络调用大模型。程序每次接收储藏温度和手持硬度后，依次完成：

1. 检查输入范围；
2. 将手持硬度换算为 `g/mm²`；
3. 用三次多项式计算温度基础货架期；
4. 根据温度和硬度计算硬度修正系数；
5. 使用二维高斯控制点进行平滑校准；
6. 计算最终货架期、预测范围、风险等级和置信度。

核心计算式为：

```text
预计货架期 = 温度基础值 × 硬度修正系数 × 二维校准系数
```

最终结果最低限制为 0.3 天：

```text
L = max(0.3, B(T) × K(T,H) × C(T,H))
```

其中：

- `T`：储藏温度，单位为 ℃；
- `H`：手持硬度计读数；
- `B(T)`：温度基础货架期；
- `K(T,H)`：硬度修正系数；
- `C(T,H)`：二维平滑校准系数；
- `L`：最终预计货架期，单位为天。

### 2. 输入范围检查

程序只接受以下输入：

```text
0 <= T <= 25
60 <= H <= 90
```

温度和硬度都可以输入小数。`NaN`、正负无穷大以及超出范围的数值会被拒绝。

温度在进入模型前保留到小数点后三位。最终预计货架期和预测区间保留一位小数。

### 3. 手持硬度换算

程序先通过分段线性插值，将手持硬度计读数换算为果实硬度 `F`，单位为 `g/mm²`。

换算控制点如下：

| 手持硬度 H | 换算硬度 F（g/mm²） |
|---:|---:|
| 50 | 200 |
| 70 | 380 |
| 90 | 500 |

当前允许输入的手持硬度是 60-90。数值 50 只是换算曲线的内部控制点，并不表示程序允许输入 50。

在当前输入范围内：

```text
60 <= H <= 70：F = 200 + 9 × (H - 50)
70 <= H <= 90：F = 380 + 6 × (H - 70)
```

例如：

```text
H = 60  →  F = 290 g/mm²
H = 70  →  F = 380 g/mm²
H = 80  →  F = 440 g/mm²
H = 90  →  F = 500 g/mm²
```

换算后的 `F` 主要用于预测范围、风险等级和置信度判断。核心货架期中的硬度修正系数直接使用手持读数 `H` 计算。

### 4. 温度基础货架期

程序使用三次多项式计算仅考虑温度时的基础货架期：

```text
B(T) = -0.00177778T³ + 0.0952381T² - 2.03175T + 24.2381
```

该公式在程序中只用于 0-25 ℃。温度越高，基础货架期整体越短。

部分基础值如下：

| 温度 T（℃） | 温度基础值 B(T)（天） |
|---:|---:|
| 0 | 24.24 |
| 5 | 16.24 |
| 10 | 11.67 |
| 15 | 9.19 |
| 20 | 7.48 |
| 25 | 5.19 |

这些数值只是第一步的温度基础值，不是最终预测结果。

### 5. 硬度修正系数

程序为每个温度控制点设置了三组“硬度—修正系数”控制值：

| 温度（℃） | H=50 | H=70 | H=90 |
|---:|---:|---:|---:|
| 0 | 0.25 | 0.79 | 1.12 |
| 5 | 0.25 | 0.79 | 1.12 |
| 10 | 0.21 | 0.78 | 1.12 |
| 15 | 0.16 | 0.76 | 1.12 |
| 20 | 0.10 | 0.73 | 1.12 |
| 25 | 0.10 | 0.72 | 1.12 |

计算过程分两步：

1. 在每个温度控制点上，根据 H=50、70、90 三个控制值进行二次拉格朗日插值，得到该温度下任意硬度的修正系数；
2. 如果输入温度位于两个温度控制点之间，再对这两个温度下的修正系数做线性插值。

因此，温度和硬度变化时，修正系数会连续变化，不会因为从一个温度档位切换到另一个档位而直接跳到另一组固定结果。

`H=50` 仍然只是内部曲线控制点；实际输入范围保持为 60-90。

### 6. 二维平滑校准

仅使用温度多项式和硬度修正后，初始结果为：

```text
L₀ = B(T) × K(T,H)
```

为了使模型在已有经验目标点附近得到指定结果，同时避免使用硬切换规则造成突变，程序增加了二维高斯平滑校准。

校准控制点如下：

| 温度（℃） | 手持硬度 | 目标货架期（天） | 温度影响宽度 | 硬度影响宽度 |
|---:|---:|---:|---:|---:|
| 0 | 70 | 37 | 7.5 | 不限制 |
| 5 | 70 | 25 | 7.5 | 不限制 |
| 10 | 70 | 17 | 7.5 | 不限制 |
| 15 | 70 | 11 | 7.5 | 不限制 |
| 20 | 70 | 7 | 7.5 | 不限制 |
| 25 | 70 | 4 | 7.5 | 不限制 |
| 25 | 60 | 2 | 7.5 | 8.0 |

每个控制点产生一个高斯基函数：

```text
φᵢ(T,H) = exp(-((T-Tᵢ)/σTᵢ)² - ((H-Hᵢ)/σHᵢ)²)
```

前六个控制点的硬度影响宽度为无穷大，因此其硬度距离项为 0，主要用于校准温度曲线。最后一个控制点同时考虑温度和硬度，用于约束 25 ℃、硬度 60 时的短货架期。

校准系数为：

```text
C(T,H) = exp(Σ wᵢφᵢ(T,H))
```

程序启动后根据控制点建立线性方程组，求出权重 `wᵢ`。求解目标是让每个校准控制点满足：

```text
B(Tᵢ) × K(Tᵢ,Hᵢ) × C(Tᵢ,Hᵢ) = 目标货架期
```

等价的对数形式为：

```text
Σ wᵢφᵢ(Tⱼ,Hⱼ) = ln(目标货架期ⱼ / (B(Tⱼ) × K(Tⱼ,Hⱼ)))
```

程序使用带主元选择的高斯消元法求解权重，并缓存计算结果。校准在控制点之间是连续的，因此不会按档位突然切换。

### 7. 最终货架期

最终预测公式为：

```text
L = max(0.3, B(T) × K(T,H) × C(T,H))
```

屏幕上显示的结果保留一位小数；内部风险判断和预测范围计算使用的是未四舍五入的 `L`。

使用 `--details` 可以查看三个核心中间值：

```text
温度多项式基础值 B(T)
硬度修正系数 K(T,H)
二维校准系数 C(T,H)
```

### 8. 预测范围

预测范围不是额外拟合出来的上下置信区间，而是按照规则在预计货架期两侧增加一定比例。

基础范围宽度为 18%：

```text
W = 0.18
```

满足以下条件时增加宽度：

- `T >= 8 ℃`：增加 6%；
- `F < 260 g/mm²`：增加 6%；
- 最大宽度不超过 35%。

计算公式：

```text
范围下限 = max(0.3, L × (1-W))
范围上限 = L × (1+W)
```

当前手持硬度限制为 60-90，对应换算硬度最低为 290 `g/mm²`，所以 `F < 260` 在当前输入范围内不会触发。实际范围宽度通常为：

- `T < 8 ℃`：±18%；
- `T >= 8 ℃`：±24%。

### 9. 风险等级

程序按以下顺序判断风险，只要满足任意一项就进入对应等级。

**高风险：**

```text
T >= 20 ℃，或 L < 4 天，或 F < 240 g/mm²
```

**中风险：**

```text
T >= 8 ℃，或 L < 10 天，或 F < 300 g/mm²
```

**低风险：**

```text
不满足高风险和中风险条件
```

高风险条件优先于中风险条件。

### 10. 置信度

置信度是规则评分，不是统计模型计算出的概率。

初始置信度为 74%，然后按以下条件调整：

- `0 <= T <= 4 ℃`：增加 8%；
- `240 <= F <= 450 g/mm²`：增加 8%；
- `T >= 20 ℃`：减少 8%；
- 最终限制在 45%-90%。

例如，10 ℃、手持硬度 60 对应 `F=290`，置信度为：

```text
74% + 8% = 82%
```

### 11. 完整计算示例

输入：

```powershell
python cherry_shelf_life_cli.py 10 60 --details
```

程序得到：

```text
T = 10 ℃
H = 60
F = 290 g/mm²
B(T) = 11.67 天
K(T,H) = 0.524
C(T,H) = 1.861
```

因此：

```text
L ≈ 11.67 × 0.524 × 1.861
  ≈ 11.4 天
```

10 ℃高于 8 ℃，预测范围宽度为 24%：

```text
预测范围约为 8.6-14.1 天
```

风险等级为中，置信度为 82%。
